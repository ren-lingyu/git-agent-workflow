* DONE v0.3.0
CLOSED: [2026-10-04 Sun 07:14]
:PROPERTIES:
:CUSTOM_ID: v0.3.0
:END:
[[file:CHANGELOGS/v0.3.0.org][Detailed release notes]].

** Removed
- *Breaking:* Remove =refs/gaw/heads/*= registration APIs and metadata from the protocol. Use =undeploy=, explicitly resolve reported residual refs, then =deploy --branch <name>= when upgrading a v0.2 deployment.

** Changed
- Identify GAW branches by valid committed state; =refs/gaw/HEAD= directly selects =refs/heads/<name>=. Update protection, deployment and diagnostics for this model.
- =commit= uses the current worktree HEAD; =check= can succeed without deployment, while malformed selectors remain errors.
- Rename the Common Lisp source tree from =lisp/= to =asdf/=.

** Fixed
- Correct init argument errors and repeated undeploy status reporting.

** Added
- =undeploy= removes identifiable local deployment metadata while preserving history and worktrees; =branch -D= allows forced deletion subject to GAW validity and worktree checks.
