#+title: v0.1.0 Release Notes

* Overview
The first tagged release provides the core runtime for an already provisioned
GAW repository and worktree. Its capabilities are the initial release baseline,
not changes relative to an earlier release.

* Added
** Independent history and explicit workspace
- Keep agent state in an independent Git history. The first-parent chain is
  canonical GAW evolution; zero or more additional project parents retain exact
  project snapshots without merging their trees.
- Declare files and directories in an unversioned restricted S-expression at
  =.gaw/config=. Read strict UTF-8 without reader evaluation; reject invalid
  paths, reserved namespaces and content outside the declared workspace.
- Validate project-parent tip trees against workspace and reserved-path
  conflicts. This is a local tree check, not an audit of every ancestor.

** Daily commands
- =git gaw commit= uses the complete index and the current worktree's symbolic
  HEAD. Run it at the GAW worktree root. It validates the candidate workspace,
  resolves each supplied project revision once, and conditionally updates the
  branch so a concurrent ref move is not overwritten.
- Compose messages with repeated =-m= and =-F= options, including =-F -= for
  standard input. Use =--allow-empty= for an unchanged tree without project
  parents and =--allow-empty-message= when intentionally supplying an empty
  message. An unchanged-tree project association is meaningful without
  =--allow-empty=.
- =git gaw show= delegates to Git while enforcing first-parent traversal and
  defaulting to first-parent merge diffs. It accepts ordinary show options,
  revisions and paths subject to those restrictions.
- =git gaw check= reports committed/staged workspace validity and local
  readiness. Warnings do not fail the command; error findings do. It does not
  stage files or include unstaged changes in the candidate.
- Provide overview and command-specific help, =git gaw version= and
  =git gaw --version=.

** Optional protection and Nix packaging
- An optional repository-local configured reference-transaction hook blocks
  ordinary object updates to exactly registered GAW branches, including updates
  through symbolic refs. This is a local accidental-update guard.
- Build and install =git-gaw= with the Nix flake and expose
  =git-agent-workflow= through its default overlay.

* Compatibility and migration
There is no earlier released version to migrate. Setup must supply the GAW
history, branch registration, selector, worktree and any desired hook before
using the runtime. A minimal daily loop is:

#+begin_src text
  git gaw check
  git gaw version
  # edit declared workspace files
  git status
  git diff
  git add <explicit-workspace-paths>
  git gaw commit -m "Record current knowledge" [project-commit...]
  git gaw show
#+end_src

* Limitations
- The supported packaged environment is x86_64-linux with Nix flakes and Git
  2.54 or newer for configured hook support.
- There are no CLI provisioning, deployment or branch lifecycle commands.
- Ordinary direct changes to =refs/gaw/*= are not yet protected. The broader
  namespace protection is introduced in v0.2.0.
- The workspace format and public interface may change before a stable release.
