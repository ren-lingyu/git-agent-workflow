#+title: v0.3.0 Release Notes

* Overview
GAW branch identity now follows complete committed-state validation instead of
local registration. Deployment is a local selection, not the source of
identity.

* Removed
** Breaking: registration protocol and APIs
Remove the =refs/gaw/heads/*= registration layer and its APIs. The selector now
points directly to the ordinary branch:

#+begin_src text
  # v0.2 layout
  refs/gaw/HEAD -> refs/gaw/heads/<name> -> refs/heads/<name>
  # v0.3 layout
  refs/gaw/HEAD -> refs/heads/<name>
#+end_src

=deploy= does not automatically migrate the old selector chain. Follow the
migration sequence below before selecting an existing valid branch.

* Changed
- Recognize any local branch with valid committed GAW state as a GAW branch,
  without a separate registration record. Multiple branches may independently
  carry valid GAW history.
- Protect existing valid GAW branches from ordinary movement or deletion. Once
  a config marker exists, ordinary updates must preserve its exact tree entry;
  first introduction remains allowed. Query failures fail closed. Direct
  ordinary mutations of =refs/gaw/*= remain blocked.
- =commit= operates on the valid branch checked out in its worktree without
  requiring deployment. =check= reports a missing selector as a warning;
  malformed, dangling or invalid selectors remain errors.
- Rename the currently selected formal branch with =branch -m=. Delete only
  unselected direct branches with valid committed state and no worktree.
- =deploy= fully validates existing local candidates, refuses malformed or
  unexpected metadata, and performs no implicit network access.
- Update status classification and diagnose health criteria for the new model;
  unexpected protocol refs are health failures in diagnostic mode.
- Rename the Common Lisp source tree from =lisp/= to =asdf/=.

* Fixed
- Report command-specific argument errors for init and deploy.
- Correct status reporting when undeploy is repeated.
- Align help and README with deployment-independent check behavior.

* Added
- =git gaw undeploy= removes the selector and owned hook configuration while
  preserving branches, history, config and worktrees. It safely removes exact
  discoverable legacy registrations, preserving damaged or unknown metadata for
  explicit review and reporting incomplete cleanup as failure.
- =git gaw branch -D <name>= skips native safe-delete ancestry checks while
  retaining the GAW validity, selection and worktree constraints.
- Dedicated =help hooks= and =help recovery= topics.

* Compatibility and migration
For a v0.2 deployment, use the new executable to exit old local deployment
state and then select the existing history:

#+begin_src text
  git gaw undeploy
  # Explicitly resolve reported residual refs if necessary.
  git gaw deploy --branch <name>
#+end_src

No history rewrite or automatic content repair is involved. Partial cleanup is
not rolled back; after explicit resolution, undeploy may be repeated. Select a
different branch or undeploy before deleting the selected branch.

* Limitations
The original release notes report successful test and package builds. That is
historical reported validation, not a new execution during this backfill.
Protection remains local, and unknown metadata is not silently repaired.
