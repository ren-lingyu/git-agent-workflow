usage: git gaw check [--branch <name>]

Check whether the current GAW worktree is ready for the normal
edit, stage, commit, and show loop.  The check is read-only and may run from a
subdirectory, although git gaw commit itself must run at the worktree root.

The report covers the optional GAW selector, HEAD config and workspace, associated
project parents, the staged candidate, conflicting Git operation state, and
the optional repository-local branch-protection hook.
It does not replace git status or git diff and does not inspect untracked or
unstaged changes.

Exit status is 0 when no error finding exists and 1 otherwise.  Warnings do
not make the report fail.  A missing selector is a warning, not a deployment
prerequisite.  A missing or divergent protection hook is also a warning
because it is a local guard rather than a runtime prerequisite.

Config v0 and v1 are supported. Unknown top-level v1 fields produce separate
HEAD and index warnings without making the check fail. Unsupported config
versions are reported explicitly and prevent readiness.

--branch checks only that local branch's committed state, without requiring a
worktree or examining the caller's index/operation state. It never reports
worktree readiness. Formal and canonical Auxiliary branches are supported.
Current Auxiliary worktrees use <uuid>/.gaw/config and UUID-relative workspace
paths; entries outside that UUID directory are invalid. Aux check adds safe
deletion readiness, without treating lack of integration as structural damage.
