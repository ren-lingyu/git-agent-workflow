GAW hook protection

The repository-local gaw-reference-transaction named hook guards refs/gaw/*,
prevents ordinary Git from moving or deleting branches whose current tip is
valid GAW state, and preserves an existing .gaw/config marker unchanged on
GAW-like branches. It is a local guard against mistakes, not an authorization
boundary. A first appearance of the marker is not blocked.

GAW lifecycle operations selectively disable this named hook for validated
ref updates. For deliberate manual recovery, a user may explicitly run a
native Git command with -c hook.gaw-reference-transaction.enabled=false.
That bypass does not validate GAW invariants; inspect the result afterward.

An unsupported config version is indeterminate: the hook conservatively
rejects branch movement even if the config marker would remain unchanged.
Role metadata and non-blocking config warnings do not change protection.
