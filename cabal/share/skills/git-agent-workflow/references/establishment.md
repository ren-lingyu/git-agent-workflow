# Establish a recoverable knowledge baseline

Apply the main skill's snapshot, provenance, checkpoint and authorization rules.
Use this workflow to establish an absent or materially insufficient knowledge
baseline in the target GAW history: an initialized formal workspace with little
project knowledge, a new Auxiliary, or an independent discovery line needing its
initial maintainable state. With a sufficient baseline, newly found earlier
material belongs to [memory maintenance and supported reconstruction](memory.md),
not a mandatory repeat of establishment.
Establishment does not require creating or redeploying a GAW workspace.
For an initial formal baseline spanning different knowledge scopes, combine
this workflow with [consolidation](consolidation.md), without first converting
every source into an Auxiliary.

## Bound the knowledge and evidence

Recover existing memory and confirm the valid target workspace and permissions
before writing. Formal and Auxiliary use the same single-source knowledge
workflow; their authority and history boundaries differ. In an Auxiliary,
also read [its layout and lifecycle rules](auxiliary.md).

A source is a coherent bounded scope of knowledge, not necessarily one file,
session or agent. Continuous work across sessions and tools can share that
scope. Identify the intended baseline, material to examine, evidence horizon,
known omissions and what is already preserved. Do not narrow the horizon to
the currently visible conversation or duplicate established knowledge.
Conversely, material from one session need not belong to just one discovery line.

Survey the agreed material before selecting states. Locate consequential
findings, motivations, decisions, corrections, verification and unresolved
questions, and distinguish supported chronology from uncertain ordering.
Identify material gaps before claiming coverage. A current project observation
can check a present claim; it cannot prove that an earlier agent observed it.

## Build the baseline and useful evolution

Distill the knowledge needed to continue within this scope: the objective,
current supported understanding, consequential reasons, outstanding questions,
evidence limitations and next action. Distinguish adopted conclusions from
superseded proposals and unsupported claims. Use the declared workspace's
existing organization rather than a required set of files or source IDs.

Apply the main skill's screening before the first target writes, staging and
checkpoints, equally in formal GAW and Auxiliary. Distill useful knowledge;
do not import complete conversations for possible future audit or defer
Auxiliary sanitization until a later formal integration. Raw evidence needs
its own archival decision, not blanket retention for establishment.

For earlier states, [Reconstruct supported earlier states](memory.md#reconstruct-supported-earlier-states)
remains authoritative for evidence horizon/coverage, supported state selection,
relative ordering, gaps, commit times and exact project provenance. Establishment
organizes the initial baseline; it does not redefine those recovery rules.

Assess raw evidence separately through [the archive workflow](archive.md).
Saving all original material is not a prerequisite for establishing knowledge.
Choose project parents only for exact project snapshots supported by actual
work or inspection, using the main skill's rules; copying a formal config into
an Auxiliary root establishes no historical project provenance.

## Review and continue

Review the full workspace as a recoverable state, including its references and
the boundaries of what was examined, inferred or remains unknown. It must not
require unpreserved temporary inputs to explain its conclusions. State partial
coverage explicitly rather than treating a useful baseline as complete recovery.
Stage/check/checkpoint through the main skill only when authorized and when the
state has independent recovery value; no fixed checkpoint count is required.

Once the baseline is sufficient, continue ordinary memory maintenance. Reopen
establishment only when the target history's baseline is absent or materially
insufficient, not for each batch of new material.
