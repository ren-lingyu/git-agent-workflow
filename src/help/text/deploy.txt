usage: git gaw deploy [--branch <name>] [--worktree-path <path>]

Materialize local GAW deployment metadata for an existing local branch whose
tip is valid GAW committed state.  Without --branch, use a valid refs/gaw/HEAD
or discover a unique valid local branch.

Deployment creates or validates the exact local symbolic registration and
refs/gaw/HEAD, reconciles an optional linked worktree, and installs the
repository-local configured protection hook.  It does not fetch, access a
remote, or create a missing source branch.

Options:
   --branch <name>         select an existing local source branch
   --worktree-path <path> create or validate a linked worktree at path
   --help                  show this help
